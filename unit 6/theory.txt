JAVA Connection Framework --- ( JCF )

it is a framework provided by java to handel the data structures and their related operations like sorting , searching , etc with flexibility. 
In other words it provides us a kind of tempelate code for the implementation of the data structures like list, set, queue , etc.
instead of writing the code for their implementation from the scratch.
Java Connection contains interfaces and classes for the achieving the functionalities previously mentioned.  


------------------------------------------------------------------------------------------------------------------------------------------------------------------

There are two families exist in java collection framework - 

1. iterable   
2. Map

Iterable is the super interface of the collection interface , which eventually gives birth to the 3 sub interfaces ( list , queue , set)

On the other hand , Map interface gives bith to the sub interface name - SortedMap . 


To work with data structures he have different classes like arrayList , HashSet , PriorityQueue , HashMap etc are the classes which acquire properties of these interfaces to make the task done.

        HashMap<Integer, Integer> map = new HashMap<>();

        for(int i = 0 ; i < nums.length; i++){
            if(map.containsKey(nums[i])){
                int currFreq = map.get(nums[i]);
                int upFreq = currFreq + 1;
                map.put(nums[i], upFreq);

                map.put(nums[i], 1);
            }

        }

JDBC -- Java Database Connectivity Is an API (Application programming interface) , provided by Java to make the java application able to interact 
relationla databases

***Note - It is speacially designed for interacting with relational databases but through some non-native mechansim it can even interact with non-realtional databases as well



JDBC provides drivers and with the support of classes like -- 

1. DriverManager - it establishes the connection with the database using getConnection() menthod.

2. Collection - it holds the current session in form of its object returned by getConnection() method

3. Statement / Prepared Statement - these classes are being used to create Statemensts for executing the query. 
                                    Statement class works with simple query(Fixed values). Where as Prepared Statement class works with parameterised classes(Dynamic values)
                                    (We prefered to use Prepared Statment class over Statement class just because it provide protection from a cyber attack name SQL Injection.)

                                    Statement class has createStatement() method to create the statements and Prepared Statement class has prepareStatement() method 

4. ResultSet - is a class which holds the result returned by database in the form of rows. and we traverse over the data of those rowsto get the exact resut.


**** Speacial Note -- All these classes exist in the java.sql pacakage. And most of them come across an exception name SQLException while dealing with JDBC.
